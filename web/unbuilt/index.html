This binary was built without the web UI.

The server is running normally and the API, the CLI and the SDKs all work against it. Only the web interface is missing: web/dist held no built bundle when this binary was compiled, so there was nothing to embed.

Build the UI onto the embed target, then compile again:

bash build-ui.sh
go build -o brokoli .

Released binaries and container images always carry the UI; the release build refuses to publish one that does not. A binary built with go install, or from a clone where build-ui.sh has not run, shows this page.
